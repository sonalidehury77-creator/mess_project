# 🍽️ Smart Hostel Mess Management System

> A modern, secure, and intelligent web-based Hostel Mess Management System developed using PHP and MySQL. This project digitizes hostel mess operations by providing separate Student and Admin portals with real-time meal management, billing, reports, announcements, and analytics.

---

# 🎯 Project Objective

The objective of this project is to automate hostel mess management by replacing manual record keeping with a secure, efficient and user-friendly web application.

The system allows students to manage meals, view bills, submit feedback and monitor their mess activities, while administrators can manage students, meals, announcements, billing, reports and analytics from a centralized dashboard.

# ⚙ Installation

```

4. Open phpMyAdmin.

5. Create database

```
mess_system
```

6. Import

```
database/mess_system.sql
```

7. Open browser

```
http://localhost/MESS_PROJECT/
