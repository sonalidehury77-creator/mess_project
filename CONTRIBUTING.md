# Contributing Guide

Thank you for your interest in contributing to this project.

This project was developed as an academic Final Year Project.

---

## Coding Standards

- Use PHP PDO
- Use Prepared Statements
- Follow MVC-like folder organization
- Validate all user input
- Escape all output
- Write clean and readable code
- Use meaningful variable names
- Comment important sections

---

## Security Rules

Always follow these security practices:

- SQL Injection Protection
- CSRF Protection
- XSS Prevention
- Password Hashing
- Session Validation
- Input Sanitization
